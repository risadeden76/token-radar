Token Radar ranks the pre-token protocols DefiLlama tracks by what a launch would be worth, calibrated on the snapshot itself: each category's multiple is the median market-cap-to-TVL ratio of its launched peers. A static dashboard shows the ranked board, a farm plan for every protocol, and the calibration behind every number.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <path/to/snapshot.json>
```
